About this Tool
What is this?

This is an in-browser Exploratory Data Analysis (EDA) tool built to let you quickly visualise and query tabular data without installing any software. Everything runs locally in your browser — no data is ever uploaded to a server.

Preloaded Datasets

Four example datasets are preloaded and ready to use from the Dataset dropdown at the top of the page. These are partitioned by district and cached in your browser so subsequent loads are instant:

  • Bridge Condition & Owner Area — asset condition ratings by owner and area
  • Construction Procurement — active and planned construction contracts
  • Current Enacted Plan — current program-year enacted plan data
  • Program Management Authorized — detailed authorized program management data

Use the Refresh Cache button to pull the latest version of any dataset from the server.

Adding Your Own Data

You can load your own .csv or .parquet file and query it alongside the preloaded datasets. This feature is available exclusively on the SQL tab:

  1. Switch to the SQL view using the chart-type buttons at the top right.
  2. Click the + Add button in the Data Sources panel on the right.
  3. Choose From URL to point to a publicly accessible file (CORS required), or Local File to upload directly from your computer.
  4. Give the source a short table alias (letters, numbers, underscores) — this becomes the SQL table name.
  5. Click Add & Load. The file is parsed and stored in your browser’s IndexedDB so it persists across page refreshes.

User-added sources are stored entirely in your browser and are never sent to any server. To remove a source, click the × next to it in the SQL sidebar.

SQL Workbench

The SQL tab runs queries in-browser using DuckDB-WASM. You can join your own data against the preloaded datasets, filter, aggregate, and export results to CSV — all without a backend.
